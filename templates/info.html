Il progetto

CyberSec Monitor è una web application sviluppata per la gestione degli eventi di sicurezza informatica. Consente di registrare, visualizzare, cercare, filtrare, modificare ed eliminare eventi attraverso un'interfaccia web.

Tecnologie utilizzate

Python Flask MySQL HTML CSS Bootstrap JavaScript Git
